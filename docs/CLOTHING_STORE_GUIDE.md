# راهنمای فروشگاه لباس (RTSP زنده + دو طبقه)

## ۱. تعریف دوربین‌ها و زون‌ها
نمونهٔ آماده: `resources/store_layout.clothing.example.json` (۲ طبقه، ۵ دوربین، رگال‌ها و اتاق پرو).
آن را کپی کنید و آدرس دوربین‌ها را بگذارید:

```bash
cp resources/store_layout.clothing.example.json resources/store_layout.json
```

هر دوربین: `floor`، `source` (آدرس RTSP) و `process_fps`. رمز را در URL ننویسید؛ از `${CAM_FLOOR_01_PASS}` استفاده کنید و در `.env` یا محیط تعریف کنید.
هر زون: `floor`، `camera_id` (فقط در تصویر همان دوربین تشخیص داده می‌شود)، `polygon` (روی تصویر دوربین) و `plan_polygon` (روی نقشهٔ طبقه).

## ۲. رسم رگال‌ها و کالیبراسیون (روی کامپیوتر با صفحه‌نمایش)
```bash
pip install opencv-python numpy
python pipeline/roi_tool.py --store clothing_1 --camera CAM_FLOOR_01 --plan-image plans/floor1.png
```
کلیک چپ = نقطه، Enter = پایان زون (id و نام را می‌پرسد)، `c` = کالیبراسیون (۴ گوشهٔ کف در تصویر دوربین و همان ۴ نقطه روی نقشه)، `s` = ذخیره.
بعد از کالیبراسیون، `plan_polygon` همهٔ زون‌های آن دوربین خودکار محاسبه می‌شود و موقعیت پای هر نفر در `metadata.plan_x/plan_y` ثبت می‌شود.

## ۳. اجرای زنده
```bash
python pipeline/run_live.py --layout resources/store_layout.json --store clothing_1 \
    --fps 3 --post http://localhost:8000/events/ingest
```
- یک thread و یک مدل YOLO برای هر دوربین؛ قطع شدن جریان = اتصال مجدد خودکار (backoff تا ۳۰ ثانیه).
- فقط آخرین فریم پردازش می‌شود، پس کندی CPU باعث عقب افتادن نقشه نمی‌شود.
- اگر کند بود: `--fps 2` یا فقط یک طبقه: `--floor 2`.
- رویدادها در `events_live.jsonl` ذخیره و هر ۵ ثانیه به API ارسال می‌شوند.

## ۴. مشاهدهٔ هیتمپ
صفحهٔ `http://localhost:3000/hitmap` — سوئیچ بین طبقه‌ها، رنگ هر زون بر اساس تعداد بازدید، رتبه‌بندی پرتردد‌ترین بخش‌ها (اتاق پرو هم یک زون عادی است). API: `GET /stores/{id}/heatmap?floor=2`.

## محدودیت‌های فعلی
- تشخیص «کدام لباس برداشته شد» (تعامل با قفسه در سطح محصول) پیاده نشده؛ فقط زون/رگال.
- شناسایی مجدد بین دو طبقه براساس اندازهٔ قد/زمان است و دقیق نیست؛ شمارش بازدیدکنندهٔ یکتا بین طبقه‌ها تقریبی است.
- چند دوربین زندهٔ واقعی روی سخت‌افزار شما تست نشده؛ نرخ فریم را با `--fps` تنظیم کنید.
